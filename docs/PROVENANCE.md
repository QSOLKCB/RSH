# Provenance and implementation boundary

RSH v2 is an independent repository built from the Robitaille–Slade Helix v1
collaboration package and standard Frenet–Serret differential geometry.

The implementation preserves the credited RSH invariants and rewrites the
software into a tested evidence runner with explicit numerical and scientific
boundaries. Context archives were used to identify useful generic capabilities
such as receipts, bounded sampling, command-line evidence, and offline
visualisation. Their source files, authored assets, specialised terminology,
and model-specific geometry were not copied into this repository.

## Terminology

The path has three neutral landmarks:

- **entry**: first discrete sample;
- **centre**: exact \(p=0.5\) sample after coordinate normalisation;
- **exit**: final discrete sample.

These names describe positions in the generated path and carry no anatomical or
cosmological interpretation.
